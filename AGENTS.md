# Правила репозитория GeoIntel

После нулевого дня файл меняется только совместным решением обоих разработчиков.

---

## 1. Команда

| | Разработчик A — «Данные» | Разработчик B — «Сервис» |
|---|---|---|
| Отвечает за | всё, что считает числа | всё, что отдаёт числа наружу |
| Границы | спутники, индексы, батч, модели | база, API, деньги, почта, деплой |
| Ветки | `feat/a-*` | `feat/b-*` |
| Лог работы | `docs/log/a.md` | `docs/log/b.md` |

Точка стыка одна: таблица `metric_value`. A пишет, B читает.

## 3. Git

- В `main` не коммитим напрямую, только через PR.
- Одна задача — одна ветка — один PR. PR больше 400 строк разбиваем.
- Перед пушем всегда `git pull --rebase origin main`. История линейная.
- `git push --force` — только в свою ветку, в `main` никогда.
- Мержит автор после апрува второго. Апрув не задерживать дольше 30 минут.

Ветки: `feat/a-vhi-indices`, `fix/b-scope-422`, `chore/b-cloudrun`.

Коммиты: `feat(indices): compute VHI from VCI and TCI`.

Конфликт в общем файле означает нарушение правила владения. Не разрешаем в одиночку: откатываем свою правку, пишем владельцу.

## 6. Конвенции

- Python 3.12, типы обязательны в сигнатурах публичных функций.
- Слои: `providers` → `domain` → `api`. Зависимости только вниз. **Домен не импортирует `earthengine-api`. API не импортирует провайдеры.**
- **Весь код на английском**: имена, комментарии, коммиты, названия колонок, сообщения логов. Комментарии только про «почему», не про «что».
- Мёртвый код удаляем, не комментируем. Слоёв совместимости не пишем.
- Деньги — целое число тыйынов. Площади — гектары, float. Даты в базе — UTC.
- Единица времени — **декада**: 1–10, 11–20, 21–конец месяца. Не неделя.
- Пользователю время в Asia/Bishkek. Конвертация в одной функции на границе API.

## 7. Правило `min_scope` — блокирующее

Каждая метрика объявляет минимальную географию, на которой её разрешено показывать. Запрос метрики на более мелкой географии возвращает **422**, а не `null` и не значение с оговоркой.

Причина: SMAP даёт 9 км на пиксель — 8100 гектаров. В Баткене туда попадут поля, склоны и камни.

Нарушение — блокирующее замечание на ревью.

## 8. Языки

Три пользовательских языка: русский, кыргызский, английский.

- Каталоги строк: `i18n/ru.json`, `i18n/ky.json`, `i18n/en.json`. Владелец — B.
- Ключи строк — только английские, вида `alerts.threshold_breached`.
- Язык берётся из профиля клиента, при отсутствии — из заголовка `Accept-Language`, по умолчанию русский.
- Отсутствующий перевод падает на русский, а не показывает голый ключ.
- Названия административных единиц лежат в базе тремя колонками: `name_ru`, `name_ky`, `name_en`.
- Интерфейсные строки на кыргызском переводит человек. Тексты, которые генерит модель, — на всех трёх языках.
