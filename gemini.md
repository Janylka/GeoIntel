# Контекст настройки проекта GeoIntel

Этот документ описывает процесс настройки локального окружения для проекта GeoIntel, возникшие проблемы и их решения.

## Цель

Настроить локальное окружение для разработки, включая базу данных PostgreSQL с PostGIS, зависимости Python и структуру проекта, чтобы два разработчика (А и B) могли начать параллельную работу.

## Текущий статус

Проект почти полностью настроен. Мы находимся на последнем шаге перед тем, как база данных будет готова к работе. Осталось успешно выполнить первую миграцию.

## Что было сделано

1.  **Структура проекта**: Создана иерархия папок (`geointel`, `tests`, `scripts` и т.д.).
2.  **Зависимости**: Настроен `pyproject.toml` для управления зависимостями через `uv`. Зависимости установлены.
3.  **Исходный код**: Все первоначальные файлы `.py` были перемещены из корневой папки в правильные директории (`geointel/contracts`, `geointel/db` и т.д.).
4.  **Конфигурация БД**: Создан файл `.env` из шаблона `.env.example` для хранения `DATABASE_URL`.
5.  **Миграции**: Настроен `Alembic` для управления схемой базы данных. Созданы файлы `alembic.ini` и конфигурация окружения в `geointel/db/migrations/`.

## Возникшие проблемы и их решения

1.  **`ModuleNotFoundError: No module named 'geointel'`**:
    -   **Проблема**: Python не видел `geointel` как пакет.
    -   **Решение**: Создан `geointel/__init__.py` и исправлена конфигурация в `pyproject.toml`.

2.  **`error: Multiple top-level modules discovered`** при `make install`:
    -   **Проблема**: Исходные файлы `.py` находились в корне проекта.
    -   **Решение**: Все файлы были перемещены в соответствующие подпапки.

3.  **Ошибки Alembic (`No 'script_location'`, `Can't find env.py`)**:
    -   **Проблема**: Отсутствовали или находились не в тех местах файлы конфигурации `Alembic`.
    -   **Решение**: Созданы `alembic.ini`, `env.py`, `script.py.mako` и перемещены в правильные директории.

4.  **`DATABASE_URL environment variable is not set`**:
    -   **Проблема**: Скрипт миграции не мог найти данные для подключения к БД.
    -   **Решение**: Создан файл `.env` командой `cp .env.example .env`.

5.  **`AttributeError: 'Config' object has no attribute 'config_main_section'`**:
    -   **Проблема**: Использование устаревшего атрибута в `env.py`.
    -   **Решение**: Замена `config.config_main_section` на `config.config_ini_section`.

## Следующий шаг для продолжения

1.  Выполнить команду `make migrate` еще раз. После внесенного исправления она должна завершиться успешно.
2.  Выполнить `make seed` для наполнения таблицы `admin_unit`.
3.  Выполнить `uv run python -m geointel.scripts.seed_dev_metrics` для генерации тестовых данных.
4.  После этого окружение будет полностью готово к дальнейшей разработке по плану.
