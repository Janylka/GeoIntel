## 2. Ключевое архитектурное решение

**Earth Engine никогда не вызывается из HTTP-запроса.**

Расчёт NDVI по району занимает от 10 до 60 секунд. Дашборд с живыми вызовами GEE не взлетит и зависнет на демо.

```
Cloud Scheduler (ежедневно 04:00 +06)
        ↓
Cloud Run Job — батч
        ↓ считает индексы в GEE по всем районам
PostgreSQL — готовые агрегаты + предрассчитанные GeoJSON
        ↓ миллисекунды
FastAPI на Cloud Run
```

Побочная выгода: ежедневный батч, который сам принимает решения об алертах, — это и есть требуемое организатором доказательство «AI работает в проде непрерывно».

## 3. Слои данных и правило разрешения

### 3.1 Правило, которое нельзя нарушать

**Каждая метрика объявляет минимальную географию, на которой её разрешено показывать.**

Причина: SMAP даёт влажность почвы с разрешением 9 км. Один такой пиксель — 8100 гектаров. В Баткене, где пашня лежит узкими полосами по долинам, в него попадут одновременно поля, склоны и голые камни. Показать эту цифру в карточке поля — значит продать клиенту точность, которой у нас нет.

API **отказывает** в выдаче метрики на слишком мелкой географии. Не «показывает с оговоркой» — отказывает.

```python
class Scope(str, Enum):
    COUNTRY = "country"
    OBLAST = "oblast"
    DISTRICT = "district"
    FIELD = "field"

@dataclass(frozen=True)
class MetricDef:
    id: str
    source: str
    native_resolution_m: int
    min_scope: Scope       # мельче — запрещено
    unit: str
    higher_is_better: bool
```

### 3.2 Реестр слоёв

| Метрика | Источник | Разрешение | min_scope | Фаза |
|---|---|---|---|---|
| `ndvi` | Sentinel-2 SR Harmonized | 10 м | FIELD | P0 |
| `ndvi_hist` | MODIS MOD13Q1, 2000–2025 | 250 м | DISTRICT | P0 |
| `lst` | MODIS MOD11A2 | 1 км | DISTRICT | P0 |
| `vci` `tci` `vhi` | производные | — | DISTRICT | P0 |
| `spi_1` `spi_3` | CHIRPS Daily | 5 км | DISTRICT | P1 |
| `soil_moisture` | SMAP L4 SPL4SMGP | 9 км | **DISTRICT** | P2 |
| `ndwi` | Sentinel-2 | 10 м | FIELD | P2 |
| `yield_forecast` | регрессия | — | DISTRICT | P1 |

### 3.3 Провайдеры — обязательная абстракция

SMAP работает с 2015 года, но радар на нём вышел из строя ещё в июле 2015-го, остался только радиометр. По каталогу CEOS плановый конец жизни миссии — **сентябрь 2026**, то есть следующий месяц. Миссии продлевают регулярно, но завязываться на конкретный спутник намертво нельзя.

```
providers/
  base.py        # Protocol: fetch(geom, start, end) -> dict[unit_id, float]
  vegetation/    sentinel2.py, modis.py
  precipitation/ chirps.py
  soil_moisture/ smap.py, era5_land.py
```

Источник выбирается через конфиг, не через импорт в бизнес-логике. Подмена SMAP на ERA5-Land должна быть правкой одной строки конфига.

### 3.4 Маска пашни — критично

**Все индексы считаются только по пикселям пашни.** Маска: ESA WorldCover 2021, класс 40 (cropland).

Без неё усредним NDVI по ледникам Тянь-Шаня — 90% территории страны это горы, и цифры будут бессмысленными.

### 3.5 Формулы

```
VCI = 100 × (NDVI − NDVI_min) / (NDVI_max − NDVI_min)
TCI = 100 × (LST_max − LST) / (LST_max − LST_min)
VHI = 0.5 × VCI + 0.5 × TCI
```

`min` и `max` — исторические экстремумы **для той же декады года** за 2000–2025 по MODIS. Не за весь период — иначе август будет сравниваться с маем.

Пороги VHI: `<30` экстремальная, `30–40` сильная, `40–45` умеренная, `45–60` норма, `>60` благоприятно.

### 3.6 Прогноз урожайности — честно

Нейросеть за двое суток не обучить, и не надо. Линейная регрессия: интеграл NDVI за апрель–июль → ц/га, обучение на статистике Нацстаткома по районам за 5–10 лет.

Даёт R² порядка 0.6–0.75 и полностью защитима на созвоне с судьями. **В интерфейсе всегда показывать доверительный интервал, а не одну цифру.** Модель хорошо описывает годы, похожие на прошлые, и хуже — аномальные; это писать прямо в UI.

## 4. Время

- В базе всё в **UTC**.
- Пользователю всё в **Asia/Bishkek (UTC+6)**.
- Конвертация — единственная функция на границе API. Внутри домена локального времени не существует.
- Единица агрегации — **декада** (1–10, 11–20, 21–конец месяца), а не неделя: под неё построены MODIS-композиты.

## 5. Схема базы

```sql
admin_unit(id, parent_id, level, name_ru, name_ky, name_en, geom, cropland_ha)
field(id, customer_id, name, crop, area_ha, geom, district_id)
metric_value(unit_id, metric_id, decade_start, value, quality, PRIMARY KEY(unit_id, metric_id, decade_start))
field_metric(field_id, metric_id, decade_start, value)
yield_forecast(unit_id, crop, season_year, value, lo, hi, model_version)
alert(id, unit_id|field_id, metric_id, decade_start, severity, state, created_at)
agent_event(id, agent, action, subject, payload_json, status, created_at)
customer(id, name, phone, email, org, plan, created_at)
invoice(id, customer_id, amount_kgs, status, issued_at, paid_at)
report(id, customer_id, scope, subject_id, decade_start, storage_path, created_at)
```

`geom` — PostGIS, EPSG:4326. Границы: geoBoundaries или FAO GAUL. 7 областей + Бишкек и Ош, 40 районов.

## 6. Контракты API

```
GET  /api/units?level=oblast|district&decade=2026-08-01
GET  /api/units/{id}?decade=...            # метрики + история + прогноз
GET  /api/units/{id}/series?metric=vhi&from=2026-05-01
GET  /api/geo/units.geojson?level=oblast   # предрассчитанный, кэш на сутки
GET  /api/alerts?since=...
GET  /api/fields                            # авторизованный
GET  /api/fields/{id}
POST /api/explain     {scope, subject_id, decade, lang}  → Gemini
POST /api/reports     {scope, subject_id, decade, lang}  → PDF
GET  /api/ops/events?limit=100              # лог агентов, публичный
```

Правила:
- Метрика вне своего `min_scope` → **422** с внятным телом ошибки, не молчаливый null.
- Все ответы содержат `decade_start` и `quality`.
- `/api/geo/units.geojson` отдаётся с ETag; геометрия не меняется.

## 7. Агенты и логирование

Четыре агента. Каждый пишет в `agent_event` **в момент действия**, а не пачкой в конце.

| Агент | Что делает сам |
|---|---|
| `monitor` | тянет снимки, считает индексы, решает какие районы перешли порог |
| `narrator` | Gemini формирует объяснение и отчёт на ru/ky под конкретное хозяйство |
| `notifier` | сам рассылает письма по сработавшим порогам на участках |
| `concierge` | принимает участок при регистрации, выставляет счёт |

`agent_event.payload_json` хранит вход и выход решения. Это одновременно отладка и доказательство для судей.

## 8. Правила кода

- Архитектура — главный приоритет. Слои: `providers` → `domain` → `api`. Домен не знает про Earth Engine, API не знает про GEE вовсе.
- Не оборачивать старый код в слои совместимости. Мёртвый код удалять, а не комментировать.
- Комментарии только на английском и только там, где объясняют «почему», а не «что».
- Каждое число, которое отдаёт API, прослеживается до строки в `metric_value`. API не вычисляет, а читает.
- Заглушки и демо-данные запрещены в задеплоенной версии. Судьи тестируют вживую.
- Агент Claude Code ведёт `agents.md` в реальном времени.
